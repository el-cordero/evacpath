# Support

Use the [issue tracker](https://github.com/el-cordero/evacpath/issues) for bug
reports, reproducible questions, and feature requests.

For a useful report, include the `evacpath` version, R version, operating
system, a minimal reproducible example, and the coordinate reference system and
units of the spatial inputs. Do not attach sensitive location, infrastructure,
or evacuation-planning data to a public issue.

For use of the package, start with the
[Get started guide](https://el-cordero.github.io/evacpath/articles/get-started.html)
and the [function reference](https://el-cordero.github.io/evacpath/reference/index.html).
